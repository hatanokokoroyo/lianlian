团队协作

哪些文件该共享？

别问「在不在 git 里」，问两个问题：它是权威吗？它随仓库走吗？

随仓库走（clone 即得）
靠外部服务 / 本机
权威
必须共享，且要 review GLOSSARY.md · docs/adr/ · spec 镜像 · 工单镜像 · CODING_STANDARDS.md
必须共享，但只能给链接 GitHub issue / PR · 标签 · issue 编号 · secrets 的值（绝不共享）
派生 / 临时
可入库，但不是权威 中文译本 · 这份 deck · cheatsheet · prototype 分支 · research 笔记
只本地，给接手人就够 handoff · 架构报告 · subagent 笔记 · 调试捕获 · .env

.scratch/ 在本仓库入库，是为了换机器；它是 agent 工作副本，不是团队文档。
