# 45 · 提议审核 · 单按钮批量提交与发送锁定

**What to build:** 把「逐项接受 / 逐项拒绝」换成一次提交整张卡：勾选=采纳、不勾=拒绝，一个按钮提交。提交是一个事务，成功后把整张卡的结果作为一条不渲染的用户消息交给模型，跑一轮回复。待审期间禁用这一条会话的发送。

- [ ] 点一项即切换采纳/拒绝；每项显示编号 1..8。
- [ ] 只有一个提交按钮，文案随勾选数变化：0 项「这 N 项都不要」、部分「采纳勾选的 N 项」、全选「全部采纳」。
- [ ] 未勾选的项有折叠的「为什么」入口，理由可选；空的拒绝也落证据（「用户未采纳，未说明理由」）。
- [ ] 提交走一个事务：采纳项落判定与依据、拒绝项落拒绝证据、卡置已处理；任一步失败全回滚，卡仍待审。
- [ ] 整张卡只触发一轮模型回复；最后一条用户消息含逐项结果与理由（App 级测试断言请求体）。
- [ ] 决策消息进上下文但不渲染、不计入「N 条」；重开 app 后仍在上下文里。
- [ ] 待审时输入、照片、发送、重试禁用，并显示 `review-lock`；提交成功或失败已落库后立即恢复。
- [ ] 0 勾选时给一句「都不是？全部不要，然后跟我说哪里不对」。
- [ ] 卡片上不再有「撤销」入口（撤销 API 的删除留给下一张票）。
- [ ] 旧的逐项 `Proposals.reject` 路径删除，不再有「拒绝一项就发一轮」。
