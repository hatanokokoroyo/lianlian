# 44 · 提议审核 · 卡片进入对话时间线

**What to build:** 把提议卡从「钉在消息列表和输入条之间的面板」变成会话时间线里的一条行。新增条目类型 `ProposalCard`，在该轮条目批次的末尾落库；列表把消息与卡片行混排渲染，卡片随列表一起滚动。待审判定改成「会话里存在指向它的卡片行」，没有卡片行的旧卡一律视为已关闭。

- [ ] 开卡后，卡片紧跟在那一轮最后一条回复之后，随消息列表上下滚动。
- [ ] 8 项的卡片能一直滚到提交按钮，不再被列表或输入条裁掉；卡片不再常驻遮挡最后几条消息。
- [ ] 卡片行有稳定的 MessageId：切走会话再回来、重开 app，位置与状态都不变。
- [ ] 卡片行不渲染成消息气泡、不计入会话头部「N 条」、不进模型上下文（App 级测试断言请求体里没有这一行的文本）。
- [ ] 生成卡片后停在卡片头部（标题贴住列表顶部），不是会话最底部；判断依据就在上一屏。
- [ ] 旧库里「待审但没有卡片行」的卡：不显示、不阻塞新的 `propose_findings`、不禁用输入条。
- [ ] 不升 `SCHEMA_VERSION`、不清库；升级后旧会话与档案照常可读。
- [ ] 这张票不改变审核动作本身：逐项接受 / 拒绝 / 撤销仍是旧行为，留给下一张票替换。
