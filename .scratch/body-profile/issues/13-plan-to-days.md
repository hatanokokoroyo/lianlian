# 13: 计划展开到训练日与改期

**What to build:** 把计划的频次规则展开成日历上的具体**训练日**：按规则排出未来若干天，单日可手动改到别的日期；每个训练日存**动作快照**而不是指向计划版本的引用（改计划不得篡改历史）。

**Blocked by:** #3, #8

**Status:** resolved

- [x] "每周 3 次"这类规则展开出具体日期，且不排到同一连续天
- [x] 单日可改期到另一天，改期后原日恢复为休息日
- [x] 计划被改成新版本后，已存在的训练日动作快照不变
- [x] 未来训练日在日历数据里可查询
- [x] 展开逻辑为纯函数并有表驱动单测
