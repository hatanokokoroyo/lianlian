# 18: 会话长度阈值（提示开新会话 / 强制新开）

**What to build:** 估算一轮装配后的输入长度，到 20 万 token 提示开新会话、50 万 token 强制新开（新会话首轮即带完整档案投影，见 ADR-0006 与 spec「会话长度阈值」）。阈值判断是纯函数、可单测；token 估算先用字符数近似（中文约 1 字 ≈ 1 token、ASCII 约 4 字符 ≈ 1 token），近似规则写进代码注释。

这是从 #17 拆出来的：现有「请求超限 → 自动裁剪最旧一半历史重发一次」是**兜底**，不是阈值提示；两者都保留。
