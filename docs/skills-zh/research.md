# 研究（Research）

起一个**后台 agent** 去做研究，这样它读的时候你继续干活。用全新的上下文窗口（context window）启动它。

它的任务：

1. 对着**一手来源（primary source）**（官方文档、源码、规范、第一方 API）调查这个问题，而不是二手转述。每个说法都要追溯到拥有它的那个源头。
2. 把发现写进单个 markdown 文件，每个说法标注来源。
3. 保存到仓库已经在放这类笔记的位置；遵循既有约定，若没有约定，找个合理的地方并在报告里说明位置。
