# 状态用五轴枚举，不用自由文本

每条 `Finding` 的取值落在五条固定的状态轴上：张力（弱/正常/紧）、对称（左弱/右弱/对称）、活动度（受限/正常）、疼痛（无/有 + 0–10）、稳定性（差/正常）。自由文本只作为证据留在会话与证据字段里，不进取值位。v1 五轴全开。

**理由**：三条下游需求都要求取值可机读——2D/3D 解剖图要按状态着色、趋势要能比较同一部位前后两次的取值、锻炼计划要能"根据弱的那条轴挑动作"。任何一条只要有自由文本混进来，这三条就都得靠模型重新解释一遍，结果不可复现。

**代价**（接受）：agent 想说而这五轴表达不了的话（例如"走路时骨盆前倾""右侧脚踝内翻"）只能进证据，不能进结构化数据；新增一条轴意味着改数据结构、改配色、改计划生成——所以加轴要走 ADR，不随手加。
