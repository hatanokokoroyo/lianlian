# 纯本地运行，无后端

应用完全跑在设备上：没有服务端、没有账号、没有遥测。DeepSeek 的 API key 由用户自己在设置页填写，直连 `api.deepseek.com`。

**理由**：MVP 要验证的是"一个人是否愿意每天打开它"，账号体系与后端在这之前是纯粹的成本；同时身体照片与病史是这个产品里最敏感的数据，不落第三方服务器是产品立场而非权宜。

**代价**（接受）：key 明文留在设备上（任何人拿到手机就能拿到 key）；无多设备同步；无用量统计；限流、重试、错误提示全部自己处理。

**已考虑并推迟**：薄后端代理（key 在服务端）——等真要给第二个人用时再做，因此模型调用必须封装在一个「模型网关」接口后面，之后换实现不动上层。
