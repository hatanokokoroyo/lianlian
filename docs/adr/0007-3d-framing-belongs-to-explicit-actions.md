# 3D 身体图的取景只属于显式动作

3D 身体图把相机与可见性彻底分开：点选部位、切换层级、开关详情卡都不改变相机；只有首屏加载、重置、「只看这块」有权取景，退出隔离时恢复进入前的相机。

**背景**：上一版 spike 在选中、切层级和开关隔离时都调用同一个取景函数，重设相机位置、目标与缩放上下限。用户放大到肩胛后点一下肌肉，缩放就被清掉——"看"变成了"跳"。

**代价**（接受）：选中深层肌不会自动把镜头拉近，用户需要显式点「只看这块」；换来的是空间感稳定、每个动作可预期。

**被拒的替代方案**：选中即取景——更容易找到深层肌，但每次点选都重置缩放，等于把浏览变成一次次跳转。选中深层肌时允许改**可见性**（自动切到“深层”），这不算取景。
